# MaterialScope · 材料光谱工作台

用于本地材料试片的多波段影像处理：从相机数值与暗白参考开始，查看分区光谱，进行材料分组、异常筛查和对象测量，再交付带来源的数值结果。程序合成示范不代表真实材料数据库或现实观测。

## 启动

当前工作站已经有带锁定依赖的基础镜像。执行 `docker buildx build --builder default --load -t solo22-materialscope:1.0 .`，再执行 `docker compose up -d --no-build`。访问 `http://127.0.0.1:18922/`。默认 Docker builder 可读取本机基础镜像，其他容器型 builder 可能无法读取本地标签。

也可在 Python 3.11/3.12 环境中安装 `requirements.txt` 后执行 `python3 app.py`。`MATERIALSCOPE_DATA_DIR` 控制数据位置，`PORT` 控制端口。Compose 使用独立 `solo22-materialscope_materialscope-data` 卷；`docker compose down` 保留数据，删除卷会删除工程。正常演示服务仅监听本机映射端口。

Dockerfile 的本地 `solo12-scanweave:1.0` 仅复用 Python 与第三方依赖层；构建先清空旧 `/app`，本项目全部业务后台、数据模型和页面均为新源码。新环境没有这个本地基础标签时，可将 FROM 改为 `python:3.12-slim`，其余依赖按同一锁定文件安装；没有第三方源码、依赖目录或其他项目业务源码混入仓库。

## 页面操作

1. 点击”装载合成材料示范”，得到原始试片、暗场、白板、反射率试片和波段错位试片，另附六块已标记材料区域、两块异物反例区域和三条合成材料参考。
2. 选择原始试片，在处理页选”暗白参考标定”，确认暗场和白板，执行后得到反射率结果。默认保留略低于0或高于1的有效测量，并在报告计数，也可显式选择遮罩或裁切。
3. 选反射率试片，点击影像查看逐波段原始数值曲线；RGB/色带/伽马只影响显示。分区页可测量矩形或椭圆区域，并把反射率均值保存为材料参考。
4. 分类页给当前反射率影像的分区打材料或反例标记（同类可标多块独立区域），训练可复用分类器。验证按整块区域留出，分别给出”少漏异物”与”少误报”两种取向的每类错误、拒识、覆盖和反例漏检；样本不足（如某类只有一块区域或没有反例）时保持未决，不能上线。选择取向后可应用到同波长影像得到材料图，点击结果像素可核对逐类距离、缺测波段和判定理由。
5. 主成分、噪声调整分量、聚类、全局异常、参考谱搜索均生成新影像。分割异常图可得到对象标签、物理面积、形状与边界接触报告。
6. 光谱处理提供物理波长平滑、不等间隔一二阶导数、归一化、连续谱和吸收特征、波段表达式与指数。空间处理提供有效权重平滑、梯度、局部统计、熵、方向纹理、背景拟合、条带参考校正、有效域收缩、裁切与缩放。
7. 诊断页可查看有效覆盖、波长采样、分布、相关、均匀性、扫描线及频谱。区域、谱库、标签与数值结果均可导出。精确对象边界基于像元边，不是地理坐标。
8. 工程页提供说明、命名版本、恢复、工程ZIP导入导出、完整性检查、依赖关系、原始相机导入和后台任务。显示预设单独保存在本地，可按同名/相同物理波长映射到其他影像；工程ZIP不包含显示预设，可用显示预设API单独导出导入。

所有处理名称与默认参数来自统一注册表，页面参数JSON可修改实际处理参数。各操作的参数、输出、有效性和来源记录在结果面板。高级功能的输入没有被支持时会明确拒绝；没有静默自动插值到任意波长、跨时间分析或隐式拼接。

## 数值和容量边界

- 内部数组是 H×W×B 的 float32，`valid` 是同形逐波段布尔数组；无效位置存零，但零不等于观测。可导入共同二维mask，会广播到各波段。浮点TIFF无效位置用NaN表示。
- 每边1–1024像素，1–64波段，总采样最多1600万；每工程100影像、100分区、100材料参考、20个保存分类器。上传100MB，展开/报告包120MB。模型拟合采样上限在报告中公开；没有未测试大规模性能承诺。
- `raw`、`reflectance`、`derived`、`labels` 四种域严格分开。派生主成分/归一化结果不被自动当作反射率。物理波长nm；空间为本地图像坐标，x右、y下，像元中心是原点加(索引+0.5)乘步长。
- 暗白标定仅支持相同尺寸、相同刻度与逐带波长的参考；不做曝光自动估计、大气校正或仪器非线性恢复。平移配准不做局部形变。库匹配是共同覆盖波段的角度或RMSE比较，不是组分丰度求解或训练分类器。
- 分类器用类质心与等权类内共享协方差的马氏距离判定，类别权重不随区域大小或样本数变化。验证按整块区域留出，每类至少2块独立区域且有足够反例像素时才允许选择误判取向，否则保持未决不能上线；每类错误、拒识、覆盖与反例漏检分开报告，不用单一总体准确率代替。应用时缺测波段按像素观测子集边缘化，从不补零；关键区分波段缺失且前两类距离差不足时判为证据不足，与明确不像已知材料的未知分开；缺波段像素置信度封顶0.69。分类器固定训练区域、材料标签、波长、验证划分与所选取向的快照，之后修改分区或谱库不改变已保存的分类器及其判定结果。
- PCA和异常只用共同有效光谱；参考谱搜索不按不同材料使用不同波段范围。连续谱最多10万完整光谱。局部纹理和谱残差都可能包含真实材料差异，不能自动解释为纯噪声。
- 轮廓最多1000标签和20万简化顶点；像元边轮廓保留孔洞。标签0为背景或未匹配，不作为材料。标签图缩放只允许最近邻。
- 重复测量须同网格、同波长、同域和单位；工作集180MB以内。统计标准误差是重复变化的描述，不包含完整仪器系统误差预算。
- 单服务进程内锁与修订号保护工程写入，不支持多个服务进程共同写同一目录。后台单线程、最多8活动任务；只取消排队任务。重启将未完成任务记为interrupted，不自动重放。已计算但冲突未引用的不可变素材可能保留。
- 工程ZIP包括当前影像、材料参考、分区和命名版本，历史撤销栈不导出；ZIP导入生成新工程ID。素材摘要、结构和来源链均核验。API JSON只用于本机应用，不包含登录或远程多租户服务。

后台有效行数可用 `python3 scripts/count_backend.py --project-root . --source-root spectra --output /tmp/materialscope-backend.json` 复算。脚本、前端、空行、注释、文档及第三方依赖不计后台有效代码。
